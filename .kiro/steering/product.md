# Product Context

**Rusuh Booking Tiket** is a mobile app for purchasing concert tickets during flash-sale events with extreme traffic spikes.

Key characteristics:
- Virtual queue system (waiting room)
- NIK-based ticket allocation (1 NIK = 1 ticket per event)
- Payment via VA and GoPay
- E-ticket delivery

See `AGENTS.md` for full architecture and operating rules.
